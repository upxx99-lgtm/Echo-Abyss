# Echo Abyss

Мод для Minecraft Java Edition 26.2 на Fabric. Звуковые волны, измерение с парящими островами, своя руда, снаряжение и мини-боссы.

## Что нужно
- Minecraft Java Edition 26.2
- Fabric Loader и Fabric API для 26.2
- Для сборки: Java 25

## Что есть в моде
- Вкладка «Эхо-Бездна» в творческом режиме.
- Камертон и Эхо-колокольчик: правый клик создаёт звуковую волну, на которую сбегаются мобы.
- Эхо-ключ (телепортатор): ведёт в измерение и обратно. У него есть прочность, чинится звонкими обломками.
- Измерение из парящих островов из Эхо-камня и Глубинного эхо-камня, со звонкой рудой и руинами с сундуками.
- Звонкий слиток (4 обломка + 4 незеритовых слитка), Звонкий блок, шаблон улучшения.
- Звонкие меч, кирка, топор, лопата, мотыга, копьё и броня (улучшаются из незерита в кузнечном столе).
- Ключи и шаблоны могут лежать в сундуках обычных структур.
- Два мини-босса (Эхо-страж и Колокольный страж): свои модели, текстуры трёх настроений (спокойный, злой, раненый), анимации, полоска здоровья и свои звуки. Яйца призыва лежат во вкладке мода.
- Свои звуки (OGG) и свои частицы со своими спрайтами.

- Парящие цитадели и руины в измерении: сундуки с лутом как в городах Энда, в цитадели живёт Эхо-страж. Мини-боссы также появляются на островах сами.

## Как собрать
```
gradlew build
```
Готовый мод появится в `build/libs`. В папку `mods` кладите файл без `-sources` в названии.

## Статус
Проект собирается через GitHub Actions. Модели, анимации, звуки и частицы написаны по примерам для 26.2, но в игре полностью не проверялись. Мини-боссы пока наследуют поведение ванильного Вардена, в том числе его собственные звуки.

## Текстуры
Текстуры предметов, брони и блоков сделаны на основе ванильных (перекрашены, пропорции сохранены). Для публикации на Modrinth их нужно заменить на полностью свои.
