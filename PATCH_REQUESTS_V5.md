# Остальные требования V5 — ещё не реализованы в этом исправительном патче

Этот список сохранён из пожеланий пользователя, чтобы дальнейшая работа не потеряла требования.

1. Полностью переработать измерение в стиле Края: только разрозненные парящие острова, без центрального острова и без потолка/верхнего ограничения.
2. Перестроить генерацию данжей и крепостей: более естественные крупные структуры, визуально вдохновлённые городами Края, но с собственными блоками, формами и палитрой.
3. Добавить собственные декоративные строительные блоки и новые текстуры, похожие по назначению на блоки городов Края, но оригинальные.
4. Переделать текстуры звонкой руды, ключа, яиц призыва, звонкого камня и глубинно-сланцевого звонкого камня.
5. Добавить новые оригинальные звуки звонкой руды и убрать неподходящие старые звуки.
6. Сделать измерение светлее и добавить больше нейтральных мобов.
7. Оставить боссов только для призыва игроком: Echo Warden призывается ритуалом с камертоном, Bell Warden — ритуалом с колоколом. Они не должны естественно появляться.
8. Добавить враждебных обычных мобов измерения, спавнеры и выпадение звонких осколков.
9. Компас должен крафтиться из четырёх незеритовых материалов по диагональному/крестовому рецепту и звонкого кристалла в центре; должен находить случайный данж.
10. Ключ должен иметь новую текстуру и появляться в сокровищах, шахтах и городах Энда.
11. Шаблон улучшения должен находиться в сундуках данжей нового измерения. Его дублирование должно использовать звонкий осколок, а не звонкий блок.
12. Добавить и проверить рецепты дублирования/улучшения звонкой брони.
13. Проверить все яйца призыва: правильные текстуры, регистрация и фактический спавн сущностей через использование яйца.

В этом патче выполнены только изменения, перечисленные в README.md. Остальные пункты не выдаются за готовые.
