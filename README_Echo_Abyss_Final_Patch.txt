ECHO ABYSS — SOURCE PATCH PACKAGE

Содержимое:
- Build1.zip — первая часть исходников (90 файлов)
- Build2.zip — вторая часть исходников (90 файлов)
- Build3.zip — третья часть исходников (21 файл)

ВАЖНО:
Это пакет только с папкой src, а не полный GitHub/Gradle-проект.
Он предназначен для обновления уже существующего репозитория Echo Abyss.

КАК ПРИМЕНИТЬ:
1. Сделайте резервную копию текущей папки src в вашем репозитории.
2. Распакуйте Build1.zip, Build2.zip и Build3.zip по очереди в корневую папку репозитория (там, где лежат build.gradle и settings.gradle).
3. Для всех частей разрешите объединение папок и замену совпадающих файлов.
4. Проверьте, что файлы оказались в src/main/...; не создавайте вложенную папку вроде src/src.
5. Сохраните изменения и отправьте их в GitHub.
6. Запустите сборку проекта локально командой .\gradlew.bat build.

ОГРАНИЧЕНИЕ ПРОВЕРКИ:
Пакет содержит исходники и ресурсы, разделённые на части менее 100 файлов.
Успешная компиляция и запуск Minecraft этим пакетом не подтверждены. Сначала выполните сборку; если появится ошибка, сохраните полный лог и исправьте её до игры.
